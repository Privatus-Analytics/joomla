# Changelog

## 1.0.0 - 2026-10-20

- Initial release.
- System plugin that adds the Privatus Analytics tracking script to the site frontend. The administrator is never tracked.
- Options for site id, script host, modules, excluded paths, allowed domains, single-page app mode and manual pageviews.
- Option to skip logged-in users or chosen user groups.
- Update server and an installable zip build script.
